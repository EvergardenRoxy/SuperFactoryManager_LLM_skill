# 模组适配经验

> 按模组整理的社区实践经验。资源 ID、tag、槽位号会随模组版本和整合包变化，**写程序前让用户用 Ctrl+Space、F3+H 或 JEI/EMI 确认**。
> 这里只记录与 SFM 配合时的要点；通用写法见 SKILL.md，完整示例见 `templates.md` 和 `advanced-patterns.md`。

## 通用

- **整合包里的同名资源**：大型整合包常有多个模组提供同名物品/流体（如硫酸、各种金属粉）。不写命名空间时会全部匹配；目标机器只接受特定模组的版本时，写上命名空间。
- **通用 tag 随版本不同**：1.20.1（Forge）多为 `#forge:…`，1.21+（NeoForge）多为 `#c:…`。
- **NBT/数据组件**：SFM 无法区分（见 SKILL.md 4.4）。
- **关闭机器自带的自动弹出/自动输出**：由 SFM 统一搬运，避免两套系统互相抢物品。
- **机器朝向和侧面配置是程序的一部分**：写进标签清单和"一次性手动设置"，否则用户照抄代码也跑不起来。
- **本文件不含配方**：任何模组的配方链都按 `recipe-learning.md` 的流程从用户的 JEI 或有出处的资料获取，不要凭记忆。

## Mekanism（通用机械）

- **不写 side 时只读**：Mekanism 方块从 null 方向只能读取，必须写面。
- **侧面配置决定能力**：每个面的输入/输出由机器的侧面配置决定，程序里的面必须与之一致；配置卡可以把一台机器的配置复制给同类机器。
- **只能从输出槽抽取**：同一个面同时设为"输入/输出"时，SFM 从这个面 input 只会拿到产物，不会把原料抽回来。工厂类机器可以只开放一个面，其他面禁用。
- **化学品类型名**：MC 1.21.1+ 统一为 `chemical::`，更早版本用 `gas::` `infusion::` `slurry::` `pigment::`。
- **同一机器多种化学品**：分别送进不同面时，用精确 ID 或 `forget` 隔开，否则会串面（`advanced-patterns.md`"多段加工链"）。
- **多产物机器**（电解分离器等）：每种产物都要有出口，产出快的产物（如氢气）先进储罐缓存，见 `efficiency.md`"输出口数量规则"。
- 聚变燃料自适应速率示例见 `templates.md`。

## AE2 及附属

- **样板供应器 + 缓存箱 + SFM 按槽位分发**：适合多输入配方，开启**阻挡模式**后不需要状态机（`advanced-patterns.md`"AE 样板供应器配合"）。
- **产物必须回到 AE**：阻挡模式靠"产物返回"解除；没有实体产物的配方要在样板里换成一个可回收的标记物品。
- **多工位共用一个标签时，样板倍数 = 工位数**：例如 4 层堆叠的祭坛共用标签、用 `to each` 分发，AE 每次就必须推 4 份材料。份数不一致会导致某些工位缺料、整组卡住。也可以每层用不同的标签。
- **按 NBT 区分物品**：可以用 AE2 存储总线分区（精确匹配）先分开，再由 SFM 运输。
- **压印器类机器选型**：堆量时优先选限制多、每次只做一种配方的机器（`efficiency.md`"多材料批量合成"）；压印器模板见 `templates.md`。
- **水晶自循环**：充能、生长、粉碎组成的循环生产，见 `advanced-patterns.md`"自循环增产"。

## GregTech CEu（GTCEu Modern）

- **多方块的每个仓口都是独立方块**：输入总线、输入仓、输出仓各贴各的标签（如 `"反应釜_输入仓1"`），程序对仓口操作，而不是对控制器操作。
- **每个输入仓通常只放一种流体**：多流体配方用精确流体 ID 分别送进不同的仓口。
- **一台机器只做一个配方**：同类机器（如多台化学反应釜）按配方分成不同标签，不要让 SFM 切换配方。
- **编程电路和不消耗的催化剂属于一次性手动设置**：在程序里用注释标出（如 `-- 需要编程电路 2`），并在"怎么搭"中列出；漏了机器会不开工。
- **长化学链**：一个触发器内按工序分段，每段 input → output → `forget`；所有副产物集中收进一个出口，避免任何一台机器被副产物堵死。
- **总开关**：在管理器上接拉杆，用 `if redstone > 0 then … end` 包住整条产线，方便暂停排查。

## 神秘农业（Mystical Agriculture）

- **注魔祭坛 + 基座**：主材放进祭坛中心，其余材料放到周围基座，每个基座 1 个，常用 `output 1 to each "基座"`。
- **识别产物用 tag**：成品种子用 `with #c:seeds`（1.21+ 整合包，如 ATM10）收回，避免把材料也收走。
- **按命名空间加正则选材料**：如 `"mysticalagriculture:.*_seed_base"` 只选种子基底；"除了种子基底以外的所有材料"用 `except` 排除。
- **多层堆叠**：几层祭坛共用标签时，AE 样板倍数必须等于层数（见上方 AE2 一节）。
- 合成本身较慢，间隔用 100 刻左右即可，不需要高频。

## 资源蜜蜂（Productive Bees）

- **可配置蜜脾共用一个 ID**（`productivebees:configurable_comb`，大部分资源类蜜脾都是它，ATM10 中已确认），种类存在 NBT/数据组件里，**SFM 无法按种类分拣**；只能整体运输，或先用能识别 NBT 的模组分开。原版蜜脾和少数独立 ID 的蜜脾可以正常按 ID 过滤。
- **离心机产出流体**：每种流体都要有去处（储罐 + 溢出口），否则错误的流体占住储罐，离心机停工（`advanced-patterns.md`"防满仓卡死"）。也可以按产物把离心机分组。

## 热力（Thermal）

- 有机灌注器阵列（能量、水、肥料、种子、产物）完整模板见 `templates.md`。机器顶部统一设为输入输出面，用 Ctrl+右击批量贴标签。

## 仪式与多步骤模组（Occultism、新生魔艺、Oritech 等）

- **先确认方块能否被自动化访问**：部分仪式方块在旧版本里不是容器，SFM 访问不到，需要能模拟右键的模组；新版本可能已支持，以网络工具显示的能力为准。
- **按槽位分发**：AE 样板供应器把一份配方推进缓存箱，SFM 按槽位分给中心和基座（`advanced-patterns.md`"AE 样板供应器配合"）。
- **复杂多步骤机器**（如 Oritech 粒子加速器）：原版模组可以用状态机 + 红石感知 + 蓄能放电实现（`advanced-patterns.md`）；但很多扩展模组提供了更简单的方式，**有扩展时优先推荐扩展**，并说明状态机方案的复杂度与性能代价。
